# はじめに
Rubyのwhile文をすっかり忘れてしまってたので、復習を兼ねて記事にしました。

# while文とは？

条件が真の間、繰り返し処理を実行します。

```ruby
# 1.基本形
while 条件式
  内容
end

# 2. do付き（doは任意）
while 条件式 do
  内容
end

# 3. 1行（ do または ; で区切る）
while 条件式 do 内容 end
while 条件式 ; 内容; end

# 4. 後置while文
内容 while 条件式

# 5. 後判定while文（条件が偽でも1回実行）
begin
  内容
end while 条件式
```
いくつか形がありますが、基本形1に沿って進めます。

# while文の使うタイミングと動き
while文は、繰り返し回数が事前に決まっておらず、条件次第で終わるループに向いています。

### 例 
```ruby
i = gets.to_i

while i < 3 # iが3未満なら真。3以上なら偽
  puts i
  i += 1
end

# 実行例（例えば、受け取った値iが0の場合)
# 0
# 1
# 2
```
この場合`i`の値が`3`未満であれば、`i`が`3`になるまで処理が繰り返されます。
1回目の判定：iの値 `0` 、0 < 3は**真**
2回目の判定：iの値 `1` 、1 < 3は**真**
3回目の判定：iの値 `2` 、2 < 3は**真**
4回目の判定：iの値 `3` 、3 < 3は**偽**
最後の判定で**偽**になり、繰り返しは終了するので、4回目の`puts i`と`i += 1`は処理されません。

この例では`i`の値が小さければ小さいほど繰り返し処理は増えます。
また、`i`の値が3以上であれば、while文の処理は実行されません。

# よく似た`until`との違い
似てません。真逆です。
`until`：条件が**偽**の間、繰り返し処理を実行
`while`：条件が**真**の間、繰り返し処理を実行

```ruby
i = gets.to_i

until i > 3  # iが3より大きければ真。3以下なら偽
  puts i
  i += 1
end

# 実行例（例えば、受け取った値iが0の場合)
# 0
# 1
# 2
# 3
```

この場合`i`の値が`3`以下は、**偽**になるので、`i`が`4`（真になるまで）繰り返されます。
1回目の判定：iの値 `0` 、0 > 3は**偽**
2回目の判定：iの値 `1` 、1 > 3は**偽**
3回目の判定：iの値 `2` 、2 > 3は**偽**
4回目の判定：iの値 `3` 、3 > 3は**偽**
5回目の判定：iの値 `4`、 4 > 3は**真**
最後の判定で**真**になり、繰り返しは終了するので、5回目の`puts i`と`i += 1`は処理されません。

# セットで使用する、`break`と`next`
繰り返しのその回をスキップする`next`と、繰り返しを強制終了する`break`は`while`とセットでよく使用されます。

### break：繰り返しを強制終了します
条件の途中でも、`break`に到達した時点でループを抜けます。
```ruby
i = gets.to_i

while i < 10
  break if i == 3  # iが3になったらループを抜ける
  puts i
  i += 1
end

# 実行例（例えば、受け取った値iが0の場合)
# 0
# 1
# 2
```

`i`が3になった時点で`break`が実行され、`puts i`より前でループを抜けるので、`3`は出力されません。

### next：その回だけスキップして次へ進む
`next`に到達すると、その回の残りの処理を飛ばして次の判定へ進みます。

```ruby
i = gets.to_i

while i < 10
  i += 1
  next if i.even?  # iが偶数のときはputs i を飛ばす
  puts i
end

# 実行例（例えば、受け取った値iが0の場合)
# 1
# 3
# 5
# 7
# 9
```

`i`が偶数の時は`next`で`puts i`を飛ばすので、奇数だけが出力されます。
※ `next`使用時はカウンタ（`i += 1`）更新の位置に注意！

# まとめ
- `while`：条件が**真**の間、繰り返す。回数が決まらず「条件で終わる」ループに向く
- `until`：条件が**偽**の間、繰り返す。`while`の逆。「〜になるまで」続けたいときに
- `break`：繰り返しを途中で強制終了する
- `next`：その回だけスキップして次の繰り返しへ進む

実際にpaizaの問題を解く中で、「0円になるまで値下げを繰り返す」のように終わりの回数が読めない処理で、whileが素直に書けると実感しました。
