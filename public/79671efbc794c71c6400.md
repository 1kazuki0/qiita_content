前提条件
---
```
Ruby on Rails 7.2.3
Ruby 3.4.8
Docker環境
```

tailwindCSS（v4）の導入方法
---
[公式ドキュメント（Tailwind CSS）](https://tailwindcss.com/)を基に導入していきます。


### tailwindcss-rails gem をインストールする
実行場所：ターミナル
```
docker compose exec web bundle add tailwindcss-rails
```
GemfileとGemfile.lockにTailwindCSSの内容が自動で記載されインストールされます。
まだgemがインストールされただけなので動きません。

### Tailwind CSS をインストールします
実行場所：ターミナル
```
docker compose exec web rails tailwindcss:install
```
上記を実行するといくつかファイルがダウンロードされます。
コマンド処理が終了したら、サーバーを再起動してください。
```
docker compose restart
```

導入は以上です。容易に導入することができました。

tailwindCSS（v4）の使い方
---
### 基本的な使い方
erbファイルなどの各ビューファイルのclass属性で
- bg-white（背景を白に変更する）
- text-xl（大きめの文字サイズを指定する）

など、(上記はあくまで一例ですが）1つ1つのやりたいことを並べて記載していきます。
```
<%= link_to "Qiita", "#", class: "bg-[#5EC8B7] text-white p-2 rounded" %>
```
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4317125/c633614a-c9cf-4c41-9adf-d85de17303de.png)

### デザインルールをcssファイルに定義する
tailwind導入時、app/assets/tailwind/application.cssファイルに以下が記述されています。
```
@import "tailwindcss";
```
この記述によりTailwindのスタイルが読み込まれ、erbファイルのclass属性に直接Tailwindが用意したクラス名を入力できるようになります。
また、このcssファイルにデザインルールを定義することができます。
#### ＠theme
＠themeディレクティブ（Tailwind専用の命令文）を使用することで、
フォントや色などを名前付きで定義することができます。
以下は色を名前付きで定義します。
```
@import "tailwindcss";
@theme {
  --color-red: #DD6457;
  --color-blue: oklch(0.85 0.13 182.2);
}
```
`--color`で色を定義、`-red:`で命名、`#DD6457;`で指定したい実際の色
これにより、`--color-red` と定義した色を、`bg-red` のようにクラス名として利用できるようになります。

```
<%= link_to "Qiita", "#", class: "bg-[#766EE5] text-white p-2 rounded" %>
<%= link_to "Qiita", "#", class: "bg-red text-white p-2 rounded" %>
```
1行目は前回。2行目はredで定義した配色を利用しています。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4317125/819237b9-32cf-4911-8ed6-ccb8734fd6eb.png)

ほかに＠themeディレクティブで様々なCSSを定義することができます。
この＠themeディレクティブで定義されるCSSのことを**テーマ変数**と呼びます。
あまりにも多そうなので[公式ドキュメントのテーマ変数](https://tailwindcss.com/docs/theme)を参照してください。

#### ＠apply
簡単にいうと、Tailwindが用意したクラスの集合体を自分で作ったクラス名に置き換えているイメージです。
TailwindCSSは基本的にclassに一つずつ要素を記載していきます。
＠applyディレクティブはいくつかの要素をまとめたものを定義します。
```
@import "tailwindcss";
@theme {
  --color-red: #DD6457;
  --color-blue: oklch(0.85 0.13 182.2);
}

.button {
  @apply bg-blue text-white p-2 rounded;
}
```
buttonという名前で定義しました。＠themeで定義した`blue`も使用可能です。
```
<%= link_to "Qiita", "#", class: "bg-[#766EE5] text-white p-2 rounded" %>
<%= link_to "Qiita", "#", class: "bg-red text-white p-2 rounded" %>
<%= link_to "Qiita", "#", class: "button" %>
```
`class: "button"`だけで実装することが可能です。
決まった形を何度も使用する際に便利そうですね。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4317125/9741ebad-8558-4ea1-9a95-c9a9909573b8.png)

他にも、ダークモードに対応している＠variantや色に透明度をつける--alpha()などもありますが、長くなるので割愛します。
